# Fallhammer Character Sheet

A D&D 5e character sheet for Foundry VTT v14, in the classic Tidy 5e layout: clean information, obvious controls, and every mechanic from the dnd5e system sheet.

Early work. See `docs/ROADMAP.md` for the plan and `docs/STATUS.md` for what's verified.

Requires the dnd5e system 6.0 or later. After enabling, choose it per character under Sheet in the sheet's title bar menu.
